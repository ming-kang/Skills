# Design System Presets — Index

## Rules

- Resolve the theme by the slug the user gave you, then read only `<theme-id>.md` beside this index.
- A preset is the sole style source for that deck; never mix in another preset.
- If the user names a theme that does not exist here, tell the user; do not substitute a similar-looking preset.
