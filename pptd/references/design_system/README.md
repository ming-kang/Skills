# Design System Presets — Index

The pptd skill ships 44 design-system presets. Use them **only when the user explicitly names a theme** — self-directed design uses the scenario guides instead of auto-picking a preset (see `SKILL.md` → “1. Plan and read selectively”).

## Rules

- Resolve the theme by the slug the user gave you, then read `<theme-id>.md` beside this index. When a preset specifies a category baseline, read that one relevant category baseline plus the preset's signature (a preset's signature always overrides baseline visual defaults on conflict, never evidence boundaries). When a preset links a shared file under `shared/`, read that shared specification alongside the preset file.
- A preset is the sole style source for that deck; never mix in another preset.
- If the user names a theme that does not exist here, tell the user; do not substitute a similar-looking preset.
