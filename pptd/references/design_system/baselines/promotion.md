# Promotion Category Baseline

Category baseline for promotion presets. The preset's signature system always overrides visual defaults below (background, palette, typography, layout/density) on conflict, never evidence boundaries. Each preset's `Density Baseline` sets per-slide minimums; impose no uniform module, data, or image quotas.

## Narrative Spine & One-Idea Discipline
- **Creative spine**: Single annual/campaign proposition → audience & market evidence → big-idea waves/chapters → channel & content system → results with measurement context → next-year direction. Pass the title read-through test.
- **One idea per slide**: Slide titles state one campaign proposition or chapter message served by every module; default continuous body copy on content slides to ≤3 lines. Alternate evidence-dense slides with spacious statement slides for rhythm.
- **Next-year close**: End with next year's theme, total budget and allocation, and measurement framework—never a bare thank-you slide.

## Evidence, Campaigns, Cases & UGC
- **Measurement boundaries**: Campaign metrics (impressions, completion, engagement, conversion) must state platform, period, and sample scope; every number carries unit, time point, and source/methodology context (estimates labeled illustrative).
- **Timelines & behavioral audiences**: Timeline/pacing slides are mandatory—each wave, season, or phase needs a named cadence and phase metrics. Audience slides use funnels, tiers, or segment bars tying demographics to behavior and value (never bare percentages).
- **Outcomes over outputs**: Make a few headline metrics heroes with oversized type; visually rank outcomes (search lift, new-customer share, sell-through rate) above outputs (impressions, volume).
- **Case deep dives & UGC**: Parallel cases use fixed comparable fields (`context/problem → action/idea → execution → measured result/implication`). Social/UGC evidence cites authentic scale, shows representative content structure, and always redraws third-party platform screenshots rather than pasting unreadable captures.

## Visual Defaults & Prohibitions (Overridable)
- Maintain one consistent source of visual tension (negative space, contrast, brand color field, or full-bleed product/portrait imagery) and one decorative language. No stacked dense tables, rainbow charts, multicolor clip art, stock filler, watermarks, or confidentiality stamps.
- Expressive display face for propositions/big numbers + legible workhorse face for body/data; one brand color family + one contrasting CTA/highlight accent; reduce charts to story lines with direct labels (timelines, funnels, comparison bars).
- When signature permits, use authentic imagery and expressive crops/shapes over plain rectangular blocks.
- Inherit [slides_categories.md](../../slides_categories.md): no default cards (functional boxes exempt), no unjustified equal splits, no empty planned regions.
