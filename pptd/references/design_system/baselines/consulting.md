# Consulting Category Baseline

Category baseline for consulting presets. The preset's signature system always overrides visual defaults below (background, palette, typography, layout/density) on conflict, never evidence boundaries. Each preset's `Density Baseline` sets per-slide minimums; impose no uniform module, data, or image quotas.

## Narrative Spine & Structure
- **Opening/closing**: Open with a one-slide executive summary and a numbered, paginated contents slide. Close with numbered conclusions (claims, not summaries) and a reader-split implications slide (e.g., policymakers, operators, buyers) ending each column in actions.
- **Titles/navigation**: Body titles must be complete assertions with a one-line scope/method subtitle; pass the title read-through test. Include a chapter breadcrumb/tab bar highlighting the current chapter unless overridden by signature.
- **Synthesis & furniture**: Close most slides with a bottom synthesis strip ("How to read this slide" / "Profile interpretation" / so-what). Fix source/footnote at bottom left and page number at bottom right—never omit or decorate. Never add watermarks, confidentiality notices/stamps, copyright lines, or logo placeholders.

## Frameworks, Evidence & Charts
- **Density/layout**: Use high-density, multi-column layouts with ≥1 complex chart (stacked columns, waterfalls, lines) or multi-row/column table; never "one oversized sentence + vast whitespace." Place parallel evidence in 2–3 columns with numbered judgments (`1`/`2`/`3`: bold assertion + brief explanation).
- **One named framework**: Use one content-justified framework per slide—never a loose collage (pressure-convergence bar, phased timeline with `TODAY`/stage gates, 3-scenario table [conservative/base/accelerated], Five Forces, heat table, difficulty × impact 2×2 with watch zone, upstream/midstream/downstream value chain, or multidimensional profile matrix)—with fine vector lines, not stacked color blocks.
- **Metrics/charts**: State unit, period, and basis on every number; express uncertainty via named observable indicators, not hedging. Label marks directly (`+42% p.a.`, `TODAY`, dashed forecast lines); never rely on legends alone. Keep table borders thin without heavy fills.

## Visual Defaults & Prohibitions (Overridable)
- Pure white ground, pure black text, deep royal blue charts/graphics, gray hierarchy (≤2 primary hues/slide); bold sans-serif primary titles, sans-serif labels/numerals.
- Inherit [slides_categories.md](../../slides_categories.md): no default cards (functional info boxes exempt), no unjustified equal splits, no empty planned regions.
