# Work Report Category Baseline

Category baseline for work-report presets. The preset's signature system always overrides visual defaults below (background, palette, typography, layout/density) on conflict, never evidence boundaries. Each preset's `Density Baseline` sets per-slide minimums; impose no uniform module, data, or image quotas.

## Narrative Spine & Scanability
- **Management spine**: One-page completion verdict → core metrics vs. targets → revenue/mix analysis → variance attribution → project status (R/A/G) → cost & efficiency → next-period actions → decisions & support required. Pass the title read-through test.
- **First-page verdict**: Slide 1 is always the verdict—one sentence on overall attainment plus target vs. actual for 3–5 headline KPIs; never pad with generic/empty cover fluff.
- **30s scan / 5s verdict**: Every slide is scannable in 30 seconds and auditable alone (1 theme + 2–4 supporting points graspable in 5 seconds). Close with decision/support items listed individually with delay consequences—never a thank-you slide.

## Metrics, Attribution, Status & Commitments
- **Target / actual / attainment**: Every metric shows target, actual, and attainment rate with its "so what" (cause, impact, or next action)—no bare numbers. State unit, period, and definition/basis; label estimates.
- **Reconciling variance**: Decompose variances quantitatively into named causes summing exactly to the total gap with no unexplained remainder.
- **R/A/G status triad**: Draw progress, attainment, and R/A/G status with one unified lightweight component deck-wide. Project status pairs `status indicator + evidence (progress %, milestones) + corrective action (owner + date)`; red items without recovery plans are defects.
- **Trends & grid alignment**: Mark reporting-period boundaries on trends, annotate inflection causes in-chart, and draw dashed forecasts labeled plan/estimate. Align parallel modules by row, height, and baseline, grouped by meaning.
- **Quantified commitments**: Next-period actions specify owner, deadline/timing, and expected quantified impact.

## Visual Defaults & Prohibitions (Overridable)
- Crisp utilitarian style: no decorative fluff, 3D, pictograms-as-data, gradients, watermarks, or confidentiality stamps.
- Single sans-serif family throughout; column/right-aligned numbers; never use serif display type/numerals unless signature specifies a serif pairing.
- Neutral slate/gray + 1 accent; green/amber/red strictly for status semantics, never decoration. Simple charts (bars, lines, waterfalls), fine table rules.
- Inherit [slides_categories.md](../../slides_categories.md): no default cards (functional boxes exempt), no unjustified equal splits, no large blank areas in the main content zone (breathing whitespace allowed; never pad thin content or leave planned slots empty).
